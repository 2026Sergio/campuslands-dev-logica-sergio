# Logica matematica 055 - velocidad tiempo distancia

## Analisis

- Entrada: Velocidad y tiempo.
- Proceso: Calcular la distancia recorrida.
- Salida: La distancia.

## Reglas identificadas

1. Multiplicar velocidad por tiempo para obtener distancia.

## Pruebas

### Caso normal

Entrada: velocidad: 60, tiempo: 2

Resultado esperado: 120

### Caso borde

Entrada: velocidad: 0, tiempo: 5

Resultado esperado: 0

## Explicacion final

La función multiplica la velocidad por el tiempo para calcular la distancia.
