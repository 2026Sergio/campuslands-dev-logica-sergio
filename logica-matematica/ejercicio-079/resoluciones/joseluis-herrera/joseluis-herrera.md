# Explicación
En el siguiente ejercicio se realizó un script para validar fórmulas químicas, aplicando una regla numérica para comprobar que su peso sea mayor a cero y que su estado de validez sea verdadero. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se evalúan los elementos del registro para verificar cuáles cumplen con las condiciones numéricas y estructurales requeridas.
