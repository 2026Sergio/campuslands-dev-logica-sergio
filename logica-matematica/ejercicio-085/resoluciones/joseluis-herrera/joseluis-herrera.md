# Explicación
En el siguiente ejercicio se realizó un script para el ordenamiento de prioridades en un taller mecánico, aplicando una regla matemática que pondera el nivel de urgencia, el costo y el tiempo estimado de cada trabajo. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se comparan los resultados de cada opción para verificar cuál reparación obtiene el mayor puntaje dentro del orden de prioridades.
