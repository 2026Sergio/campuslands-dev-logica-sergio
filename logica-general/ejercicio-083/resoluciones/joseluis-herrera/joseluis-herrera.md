# Ejercicio 83

# Explicación
En el siguiente ejercicio se realizó un script para la toma de decisiones en un torneo de esports, aplicando una regla para calcular un puntaje de evaluación basado en las partidas ganadas, la precisión de tiro y el nivel de disciplina. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se comparan los resultados de cada opción para verificar cuál equipo obtiene el mayor puntaje en la decisión final.
