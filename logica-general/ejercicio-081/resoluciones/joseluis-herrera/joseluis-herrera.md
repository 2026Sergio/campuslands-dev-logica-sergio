# Ejercicio 81

# Explicación
En el siguiente ejercicio se realizó un script para clasificar jugadores en un entorno de videojuegos competitivos, aplicando una regla basada en el KDA, la cantidad de partidas jugadas y el nivel de honor. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se evalúan los elementos del registro para verificar cuáles cumplen con las condiciones necesarias para ser clasificados en la categoría de élite.
