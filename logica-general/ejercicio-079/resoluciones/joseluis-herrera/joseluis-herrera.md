# Ejercicio 79

# Explicación
En el siguiente ejercicio se realizó un script para gestionar un inventario de fórmulas químicas y reactivos, aplicando una regla para identificar cuáles se encuentran en nivel crítico y representan peligro. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se filtran y evalúan los elementos del inventario para verificar cuáles cumplen con la condición de alerta.
