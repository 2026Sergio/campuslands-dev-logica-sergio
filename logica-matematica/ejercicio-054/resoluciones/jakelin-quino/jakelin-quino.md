# Logica matematica 054 - areas y perimetros

## Analisis

- Entrada: Base y altura de un rectángulo.
- Proceso: Calcular área y perímetro.
- Salida: Área y perímetro del rectángulo.

## Reglas identificadas

1. Área = base * altura.
2. Perímetro = 2 * (base + altura).

## Pruebas

### Caso normal

Entrada: base: 5, altura: 3

Resultado esperado: area: 15, perimetro: 16

### Caso borde

Entrada: base: 0, altura: 4

Resultado esperado: area: 0, perimetro: 8

## Explicacion final

La función multiplica base por altura para el área, y suma base y altura y multiplica por 2 para el perímetro.
