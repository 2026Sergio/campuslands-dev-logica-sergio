# Ejercicio 82

# Explicación
En el siguiente ejercicio se realizó un script para procesar porcentajes y proporciones en un ranking de fútbol sala, aplicando una regla matemática para calcular el porcentaje de efectividad de victorias sobre los partidos jugados. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se evalúan los elementos del registro para verificar cuál equipo obtiene el mayor porcentaje de efectividad.
