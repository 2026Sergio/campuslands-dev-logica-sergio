# Ejercicio 81

# Explicación
En el siguiente ejercicio se realizó un script para procesar operaciones aritméticas controladas en un contexto de videojuegos competitivos, aplicando una regla matemática que suma los puntos base y la bonificación por racha, restando la penalización por muerte. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se evalúan los elementos del registro para verificar cuál partida obtiene el mayor resultado neto.
