# Ejercicio 84

# Explicación
En el siguiente ejercicio se realizó un script para calcular rangos y máximos en un inventario de motos, aplicando una regla matemática que pondera el cilindraje, el precio y el kilometraje de cada vehículo. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se comparan los resultados de cada opción para verificar cuál moto obtiene el mayor puntaje numérico dentro de los rangos evaluados.
