# Ejercicio 80

# Explicación
En el siguiente ejercicio se realizó un script para simular el costo total de pedidos de comida urbana, aplicando una regla matemática que combina el precio base, la cantidad de ingredientes y la distancia de entrega. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se evalúan los elementos del inventario para verificar cuál plato obtiene el mayor resultado numérico en la simulación.
