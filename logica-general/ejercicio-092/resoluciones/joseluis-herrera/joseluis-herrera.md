# Ejercicio 92 

# Explicación
En el siguiente ejercicio se realizó un script para resolver un caso de comparación de opciones en un reto de pingpong, aplicando una regla estructurada en funciones pequeñas que evalúa el rendimiento ponderando la velocidad de reflejos (donde un tiempo menor otorga mejor puntaje), la precisión en el smash y el nivel de resistencia. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se comparan los elementos de la lista para identificar cuál competidor obtiene la mayor puntuación global.
