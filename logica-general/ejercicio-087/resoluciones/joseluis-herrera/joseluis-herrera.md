# Ejercicio 87

# Explicación
En el siguiente ejercicio se realizó un script para la detección de inconsistencias en una playlist musical, aplicando una regla para comprobar si alguna canción presenta valores anómalos o inválidos, como una duración menor o igual a cero o reproducciones negativas. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se evalúan los elementos del registro para verificar cuáles canciones contienen errores en sus datos.
