# Ejercicio 86

# Explicación
En el siguiente ejercicio se realizó un script para procesar la conversión de unidades en un reto de autos hiperdeportivos, aplicando una regla matemática que transforma millas por hora a kilómetros por hora y libras a kilogramos para calcular un puntaje de rendimiento combinando velocidad, peso y potencia. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se comparan los resultados de cada vehículo para verificar cuál obtiene el mejor valor tras la conversión.
