# Ejercicio 86

# Explicación
En el siguiente ejercicio se realizó un script para la búsqueda de elementos en un registro de autos hiperdeportivos, aplicando una regla matemática para evaluar el rendimiento combinando la velocidad máxima, la aceleración y la aerodinámica. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se comparan los elementos de la lista para identificar y mostrar cuál vehículo cumple con la mejor puntuación en la búsqueda.
