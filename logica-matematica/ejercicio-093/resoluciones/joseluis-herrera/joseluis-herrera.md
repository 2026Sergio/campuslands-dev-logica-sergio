# Explicación
En el siguiente ejercicio se realizó un script para resolver un caso de coordenadas y distancia en un reto de paracaidismo, aplicando una regla estructurada en funciones pequeñas que calcula la distancia aproximada entre el origen y el punto de aterrizaje usando trigonometría básica, junto con una penalización basada en la velocidad del viento. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se comparan los elementos de la lista para identificar cuál zona obtiene el mejor rendimiento global.
