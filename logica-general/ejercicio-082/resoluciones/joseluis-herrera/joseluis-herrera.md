# Explicación
En el siguiente ejercicio se realizó un script para la validación de datos en un ranking de fútbol sala, aplicando una regla para comprobar que el equipo se encuentre activo, que su cantidad de partidos jugados sea mayor a cero y que tenga goles a favor registrados. A través de esa regla y usando una función flecha junto a un ciclo forEach y una condicional if, se evalúan los elementos del registro para verificar cuáles cumplen con las condiciones de validación requeridas.
