# Logica matematica 059 - validaciones numericas

## Analisis

- Entrada: Un número.
- Proceso: Verificar si el número es positivo, negativo o cero.
- Salida: Mensaje con la clasificación.

## Reglas identificadas

1. Si el número es mayor que 0, es positivo.
2. Si el número es menor que 0, es negativo.
3. Si el número es igual a 0, es cero.

## Pruebas

### Caso normal

Entrada: numero: 5

Resultado esperado: positivo

### Caso borde

Entrada: numero: 0

Resultado esperado: cero

## Explicacion final

La función revisa si el número es mayor, menor o igual a 0 para clasificarlo.
